# 🚀 Script Banner Termux Cyber Security

Script kustomisasi tampilan Termux dengan tema **Cyber Security (Hacker)**. 
Dilengkapi dengan efek **Matrix Hijau**, **Loading Bar**, dan **Banner Nama Besar** yang otomatis muncul setiap kali membuka sesi baru (New Session).

## ✨ Fitur
- Efek Matrix Hijau (Cmatrix)
- Animasi Loading Bar
- Banner ASCII Kustom (Bisa ganti nama sendiri)
- Tampilan Dashboard bertema Hacker
- Prompt Panah Hijau (`❯`)

## 🛠️ Cara Instalasi
Buka aplikasi **Termux** kamu, lalu copy-paste perintah di bawah ini dan tekan Enter:
