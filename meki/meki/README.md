# Termux Cyber Banner Manager

Script kustomisasi tampilan Termux dengan tema Cyber Security. Dilengkapi dengan menu installer dan uninstaller yang memudahkan pengguna untuk memasang atau menghapus banner.

## Fitur
- Efek Matrix dinamis (menyesuaikan warna tema).
- Banner ASCII kustom (menggunakan nama pengguna).
- 6 Pilihan warna tema.
- Tampilan Dashboard ala Cyber Security.
- Prompt terminal kustom.
- Menu installer untuk memasang dan menghapus banner dengan mudah.

## Prasyarat
- Aplikasi Termux (Android).
- Koneksi internet (untuk mengunduh dependensi saat instalasi).
